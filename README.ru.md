# Free VPN (+100TB Высокоскоростного Трафика)

Быстрый, безопасный и мультиплатформенный VPN для Windows, Android и macOS с автоматическим подключением профилей.

[Скачать для Windows](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-Setup.exe) · [Скачать APK для Android](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN.apk) · [Скачать для macOS](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-macOS.dmg)

## Возможности
- **Мгновенное подключение:** Готов к работе сразу после установки без ручного ввода учетных записей.
- **Маршрутизация всей системы:** Полная поддержка TUN на Windows и VpnService на Android.
- **Умная балансировка квот:** Автоматическое переключение профилей для равномерного распределения трафика.
- **Без ручной настройки:** Никаких сложных конфигураций.
