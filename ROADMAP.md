# Roadmap

## Current: Windows development preview

The accepted desktop interface is being integrated with the independent protocol/gateway core. Local tests cover routing rules, account profiles, recovery policy, desktop geometry and loopback transport. Real owner authentication and independent selected/direct egress checks remain required before a stable release.

## Next

- Finish real-network validation, DNS behavior checks and reliability under network changes.
- Improve first-run guidance, screen-reader/keyboard use and Persian translation coverage.
- Signed Windows distribution and a reviewed update mechanism.
- Browser-based account sign-in where the official service permits it.
