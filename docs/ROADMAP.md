# Roadmap

The current focus is a reliable Windows application using the restored original engine.

- Validate real account sign-in for the user previously affected by HTTP 406.
- Validate connection, disconnection, quota reporting and original engine app exclusions.
- Improve installation and accessibility without changing the engine's protocol behavior.
- Revisit include-only application routing only with a tested implementation.

Android, iOS, macOS, Linux, Google Play and App Store distribution are future plans. There are no current clients or approved store listings for these platforms.
