# Free VPN 1.0

Windows and Android clients using your own Mozilla account. No personal VPS is required; service eligibility, availability and quotas are controlled by Mozilla.

- A simpler Home screen with connection status, server selection and actual allowance.
- Windows launches the desktop-capable engine for Whole computer and App rules.
- Personal-account sign-in; prepared accounts and automatic quota rotation removed.
- Android updates are checked manually from Settings and require Android installation confirmation.

Validation covers local unit/regression tests, isolated empty-profile Windows startup, TUN capability, program inventory and settings persistence. It does not guarantee real Mozilla sign-in or upstream connectivity on every device/network. Real-phone testing remains outstanding.

The public release is 1.0. Windows keeps internal build 2.3.20; Android keeps version code 23020, allowing upgrades over older 2.x installations. Existing local account data is retained. Previously exposed account sessions should be revoked by their owners.
