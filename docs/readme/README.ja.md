# III85III VPN

III85III の Windows UI は III85III のオリジナル Firefox VPN Client エンジンを使用します。UI とインストーラーは III85III 名義で、エンジンは変更せず GPL ライセンスと作者表示を保持します。

自分の Mozilla アカウントと Mozilla パスワードでログインしてください。コードが必要な場合は別のウィンドウが開きます。個人の VPS は不要で、利用資格と上限は Mozilla が決定します。

このエンジンでは、チェックしたアプリは VPN の対象外となり直接接続します。選択アプリだけを VPN に通すモードは本バージョンでは提供しません。

自動テストはすべてのアカウントのログイン成功を保証しません。以前 HTTP 406 が出たユーザーの実際の接続は引き続き検証が必要です。
