# Free VPN

Firefox/Mozilla アカウントで利用できる、Windows・Android 向けの無料 VPN アプリ。

[Windows](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-Setup.exe) · [Android](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN.apk)

## 使い方

1. Firefox/Mozilla アカウントを作成します。
2. アプリを開き、そのアカウントのメールアドレスと Mozilla のパスワードを入力します。
3. サーバーを選んで接続します。

Mozilla の利用条件とデータ上限が適用されます。
