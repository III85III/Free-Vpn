# III85III VPN

رابط ویندوز III85III از موتور اصلی Firefox VPN Client ساختهٔ آرمان استفاده می‌کند. نام و ناشر رابط و نصب‌کننده III85III است؛ موتور بدون تغییر و با مجوز GPL و اعتبار سازنده همراه برنامه می‌آید.

با حساب موزیلای خودت و رمز موزیلا وارد شو؛ اگر کد لازم شد پنجرهٔ جدا باز می‌شود. به VPS شخصی نیاز نداری و دسترسی و سهمیه را موزیلا تعیین می‌کند.

در این موتور، برنامه‌های تیک‌خورده از VPN مستثنا هستند و مستقیم وصل می‌شوند؛ حالت فقط برنامه‌های انتخابی در این نسخه ارائه نمی‌شود.

این نسخه پیش‌نمایش است؛ ورود کاربری که قبلاً خطای ۴۰۶ داشت و اتصال واقعی هنوز به تست نیاز دارند.
