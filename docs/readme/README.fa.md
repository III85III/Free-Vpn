# III85III VPN

**برنامهٔ رایگان ویندوز، با حساب موزیلای خودتان**

III85III VPN یک کلاینت محلی برای حساب‌های واجد شرایط موزیلاست. به VPS شخصی نیاز ندارید؛ دسترسی به اینترنت از زیرساخت سرویس موزیلا انجام می‌شود.

> **پیش‌نمایش توسعه** — ورود واقعی به موزیلا و مسیر خروج برنامه‌های انتخابی هنوز به آزمایش عملی نیاز دارند. این نسخه نهایی نیست. رایگان‌بودن برنامه به معنی سهمیهٔ نامحدود یا دسترسی رایگان تضمین‌شده به سرویس نیست؛ موزیلا شرایط دسترسی، مناطق و سهمیه را تعیین می‌کند.

## امکانات

- فقط برنامه‌های انتخابی از مسیر VPN استفاده می‌کنند؛ بقیه مسیر مستقیم دارند.
- انتخاب دستی چند حساب با نشست‌های محلی رمزگذاری‌شده با Windows DPAPI و سهمیهٔ جداگانه.
- سرورهای محبوب و اخیر، مرتب‌سازی پینگ، اتصال مجدد با فاصله و توقف پس از قطع دستی یا خطای حساب/سهمیه.
- منوی کنار ساعت، رابط فارسی/انگلیسی، روشن/تیره و گزارش خطای بدون شناسه‌های حساب.

## دانلود و شروع

[⬇ Windows x64 · Releases](https://github.com/III85III/III85III-VPN/releases)

1. فایل III85III-VPN-Setup.exe را از Releases بگیر و اجرا کن؛ اجزای همراه را خودش استخراج می‌کند.
2. III85III VPN.exe را اجرا کن؛ برنامه ابتدا قطع است.
3. حساب موزیلای خودت را اضافه کن و تأیید ورود را شخصاً انجام بده. رمز گوگل را در برنامه وارد نکن.
4. برنامه‌ها را انتخاب و ذخیره کن، سرور را انتخاب کن و وصل شو؛ اگر ویندوز اجازهٔ مسیریابی خواست، بررسی و تأیید کن.

## محدودیت‌ها و حریم خصوصی

فقط TCP وب روی پورت‌های 80، 443، 8080 و 8443 پشتیبانی می‌شود؛ UDP برنامه‌های انتخابی رد می‌شود. DNS، IPv6، مسیر واقعی برنامه‌ها و رفتار هنگام قطعی هنوز به تست زنده نیاز دارند. هیچ حساب، ایمیل یا نشست سازنده همراه دانلود نیست؛ گذرواژه در مخزن حساب ذخیره نمی‌شود.

## تست‌ها و آینده

۲۵ تست Node، ۴۴ بررسی هستهٔ دسکتاپ و ۸۹۱ بررسی چیدمان موفق شده‌اند؛ این‌ها جای تست اتصال واقعی را نمی‌گیرند. Android، iOS، macOS، Linux و انتشار در فروشگاه‌ها فعلاً برنامهٔ آینده‌اند.
