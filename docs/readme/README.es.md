# Free VPN

VPN gratuita para Windows y Android con tu cuenta de Firefox/Mozilla.

[Windows](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-Setup.exe) · [Android](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN.apk)

## Cómo usarla

1. Crea una cuenta de Firefox/Mozilla.
2. Abre la aplicación e introduce el correo y la contraseña de Mozilla de esa cuenta.
3. Elige un servidor y conéctate.

Se aplican los requisitos de acceso y los límites de datos de Mozilla.
