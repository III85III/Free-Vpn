# III85III VPN

La interfaz Windows III85III utiliza el motor original Firefox VPN Client de III85III. La interfaz y el instalador se llaman III85III; el motor se conserva sin cambios con su licencia GPL y créditos.

Usa tu propia cuenta y contraseña Mozilla. Si se solicita un código, aparece una ventana separada. No necesitas VPS propio; Mozilla determina los requisitos y las cuotas.

En este motor, las aplicaciones marcadas quedan excluidas del VPN y se conectan directamente. Esta versión no ofrece VPN únicamente para las aplicaciones seleccionadas.

Las pruebas automatizadas no garantizan el acceso de todas las cuentas. Sigue pendiente la validación real del usuario antes afectado por HTTP 406.
