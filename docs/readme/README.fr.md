# Free VPN

Une application VPN gratuite pour Windows et Android avec votre compte Firefox/Mozilla.

[Windows](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-Setup.exe) · [Android](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN.apk)

## Utilisation

1. Créez un compte Firefox/Mozilla.
2. Ouvrez l’application et saisissez l’adresse e-mail et le mot de passe Mozilla de ce compte.
3. Choisissez un serveur et connectez-vous.

Les conditions d’accès et limites de données de Mozilla s’appliquent.
