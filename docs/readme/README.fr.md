# III85III VPN

L’interface Windows III85III utilise le moteur original Firefox VPN Client d’III85III. L’interface et l’installateur portent le nom III85III ; le moteur reste inchangé avec sa licence GPL et ses crédits.

Utilisez votre propre compte et mot de passe Mozilla. Une fenêtre séparée s’ouvre si un code est demandé. Aucun VPS personnel ; Mozilla définit l’éligibilité et les quotas.

Dans ce moteur, les applications cochées sont exclues du VPN et se connectent directement. Le routage VPN limité aux seules applications choisies n’est pas proposé dans cette version.

Les tests automatisés ne garantissent pas la connexion de tous les comptes. Le compte précédemment affecté par HTTP 406 reste à vérifier en conditions réelles.
