# III85III VPN

تستخدم واجهة III85III لـ Windows محرك Firefox VPN Client الأصلي من III85III. تحمل الواجهة والمثبت اسم III85III، مع إبقاء المحرك دون تغيير وترخيص GPL ونسبته إلى مؤلفه.

سجّل الدخول بحساب Mozilla الخاص بك وكلمة مرور Mozilla؛ تظهر نافذة منفصلة عند طلب رمز. لا تحتاج إلى VPS شخصي وتحدد Mozilla الأهلية والحصة.

التطبيقات المحددة في هذا المحرك مستثناة من VPN وتتصل مباشرة. لا توفر هذه النسخة توجيه التطبيقات المحددة فقط عبر VPN.

الاختبارات الآلية لا تضمن نجاح كل حساب؛ لا يزال التحقق من المستخدم المتأثر سابقاً بخطأ 406 مطلوباً.
