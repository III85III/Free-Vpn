# Free VPN

تطبيق VPN مجاني لويندوز وأندرويد باستخدام حساب Firefox/Mozilla الخاص بك.

[ويندوز](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-Setup.exe) · [أندرويد](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN.apk)

## طريقة الاستخدام

1. أنشئ حساب Firefox/Mozilla.
2. افتح التطبيق وأدخل البريد الإلكتروني وكلمة مرور حساب Mozilla.
3. اختر خادمًا واتصل.

تُطبّق شروط الإتاحة وحدود البيانات لدى Mozilla.
