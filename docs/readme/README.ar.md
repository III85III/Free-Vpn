# III85III VPN

**عميل Windows مجاني لحساب Mozilla الخاص بك**

III85III VPN عميل محلي للحسابات المؤهلة لدى Mozilla. لا تحتاج إلى VPS شخصي؛ تعتمد الخدمة على البنية البعيدة لموزيلا.

> **معاينة تطوير** — لم يكتمل التحقق العملي من تسجيل الدخول إلى Mozilla ومسار خروج التطبيقات. هذه ليست نسخة مستقرة. مجانية التطبيق لا تعني بيانات غير محدودة أو استحقاق خدمة مجانية؛ تحدد Mozilla الأهلية والمناطق والحصة.

## الميزات

- تمر التطبيقات المحددة فقط عبر VPN، والبقية تستخدم المسار المباشر.
- حسابات متعددة باختيار يدوي وجلسات محلية محمية بواسطة Windows DPAPI وحصة منفصلة لكل حساب.
- مواقع مفضلة وحديثة، ترتيب زمن الاستجابة وإعادة اتصال متدرجة تتوقف عند الفصل اليدوي أو رفض الحساب/الحصة.
- قائمة بجوار الساعة، واجهة فارسية/إنجليزية، مظهر فاتح/داكن وتقرير تشخيص آمن.

## التنزيل والبدء

[⬇ Windows x64 · Releases](https://github.com/III85III/III85III-VPN/releases)

1. نزّل III85III-VPN-Setup.exe من Releases وشغّله؛ يفك المكونات المطلوبة تلقائياً.
2. شغّل III85III VPN.exe؛ يبدأ دون اتصال.
3. أضف حساب Mozilla الخاص بك وأكمل التحقق بنفسك. لا تدخل كلمة مرور Google في التطبيق.
4. حدد التطبيقات واحفظها، اختر الموقع ثم اتصل وراجع طلب إذن التوجيه من Windows إن ظهر.

## الحدود والخصوصية

يدعم TCP للويب على المنافذ 80 و443 و8080 و8443 فقط؛ يُرفض UDP للتطبيقات المحددة. لا تزال DNS وIPv6 ومسارات التطبيقات والتعافي بحاجة إلى اختبار حي. لا يتضمن التنزيل حساب المطور أو بريده أو جلساته. لا تُحفظ كلمة المرور في خزنة الحساب.

## التحقق والخطط

نجح 25 اختبار Node و44 فحصاً لنواة سطح المكتب و891 فحص تخطيط. لا تعوض هذه اختبارات الاتصال الحقيقي. Android وiOS وmacOS وLinux ومتاجر التطبيقات خطط مستقبلية.
