# III85III VPN

**Бесплатный Windows-клиент для вашей учётной записи Mozilla**

III85III VPN — локальный клиент для учётных записей Mozilla с доступом к сервису. Собственный VPS не нужен: трафик проходит через удалённую инфраструктуру сервиса Mozilla.

> **Предварительная версия** — Реальный вход в Mozilla и выход выбранных приложений ещё требуют практической проверки. Это не стабильный выпуск. Бесплатность приложения не означает безлимитный трафик или гарантированный бесплатный доступ к сервису: условия, регионы и квоты определяет Mozilla.

## Возможности

- Только выбранные приложения используют VPN; остальные подключаются напрямую.
- Несколько аккаунтов с ручным выбором, локальными сессиями под защитой Windows DPAPI и отдельными квотами.
- Избранные и недавние серверы, сортировка задержки и повторное подключение с паузами; ручное отключение и ошибки аккаунта/квоты останавливают попытки.
- Меню в трее, персидский/английский интерфейс, светлая/тёмная тема и безопасный диагностический отчёт.

## Загрузка и запуск

[⬇ Windows x64 · Releases](https://github.com/III85III/III85III-VPN/releases)

1. Скачайте Windows x64 ZIP из Releases и распакуйте папку целиком.
2. Запустите III85III VPN.exe; приложение запускается без подключения.
3. Добавьте собственный аккаунт Mozilla и самостоятельно пройдите проверку. Не вводите пароль Google в приложение.
4. Выберите приложения, сохраните выбор, выберите сервер и подключитесь. При необходимости проверьте запрос Windows на маршрутизацию.

## Ограничения и конфиденциальность

Поддерживается веб-TCP на портах 80, 443, 8080 и 8443; UDP выбранных приложений отклоняется. DNS, IPv6, реальный выход и сбои ещё требуют живых испытаний. Аккаунт, почта и сессии разработчика не распространяются. Пароли не сохраняются в хранилище аккаунтов.

## Проверки и планы

Пройдены 25 Node-тестов, 44 проверки ядра и 891 проверка компоновки. Это не замена проверке реального соединения. Android, iOS, macOS, Linux и магазины приложений — будущие планы.
