# Free VPN

Бесплатное VPN-приложение для Windows и Android с вашей учётной записью Firefox/Mozilla.

[Windows](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-Setup.exe) · [Android](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN.apk)

## Как пользоваться

1. Создайте учётную запись Firefox/Mozilla.
2. Откройте приложение и введите почту и пароль Mozilla от этой записи.
3. Выберите сервер и подключитесь.

Действуют условия доступа и ограничения трафика Mozilla.
