# III85III VPN

Windows-интерфейс III85III использует оригинальный движок Firefox VPN Client от III85III. Интерфейс и установщик называются III85III; движок сохранён без изменений, с лицензией GPL и указанием автора.

Войдите со своим аккаунтом и паролем Mozilla. Если потребуется код, откроется отдельное окно. Собственный VPS не нужен; условия доступа и квоты определяет Mozilla.

В этом движке отмеченные приложения исключаются из VPN и подключаются напрямую. Режима VPN только для выбранных приложений в этой версии нет.

Автоматические тесты не гарантируют вход для каждой учётной записи. Соединение пользователя, ранее получавшего HTTP 406, ещё требует проверки.
