# Free VPN

Firefox/Mozilla hesabınızla çalışan ücretsiz Windows ve Android VPN uygulaması.

[Windows](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN-Setup.exe) · [Android](https://github.com/III85III/Free-Vpn/releases/latest/download/III85III-VPN.apk)

## Kullanım

1. Bir Firefox/Mozilla hesabı oluşturun.
2. Uygulamayı açıp hesabın e-postasını ve Mozilla şifresini girin.
3. Bir sunucu seçip bağlanın.

Mozilla hizmet koşulları ve veri sınırları geçerlidir.
