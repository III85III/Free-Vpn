# III85III VPN

III85III Windows arayüzü, III85III tarafından geliştirilen özgün Firefox VPN Client motorunu kullanır. Arayüz ve yükleyici III85III adını taşır; motor değiştirilmeden GPL lisansı ve yazar bilgileriyle sunulur.

Kendi Mozilla hesabınızı ve Mozilla şifrenizi kullanın. Kod gerekirse ayrı pencere açılır. Kişisel VPS gerekmez; uygunluk ve kotayı Mozilla belirler.

Bu motorda işaretlenen uygulamalar VPN dışında tutulur ve doğrudan bağlanır. Yalnızca seçilen uygulamaları VPN üzerinden yönlendirme bu sürümde yoktur.

Otomatik testler her hesabın girişini garanti etmez. Daha önce 406 hatası alan kullanıcının gerçek bağlantısı hâlâ doğrulanmalıdır.
