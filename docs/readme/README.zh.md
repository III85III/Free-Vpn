# III85III VPN

III85III Windows 界面使用 Arman 的原版 Firefox VPN Client 引擎。界面和安装程序以 III85III 命名；引擎保持原样，并保留 GPL 许可证和作者信息。

请使用您自己的 Mozilla 账户及 Mozilla 密码。需要验证码时会打开独立窗口。无需个人 VPS；资格与配额由 Mozilla 决定。

在此引擎中，勾选的应用被排除在 VPN 之外并直连。本版本不提供仅让所选应用走 VPN 的模式。

这是开发预览版；此前出现 HTTP 406 的用户登录及实际连接仍待验证。
