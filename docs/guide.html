III85III VPN

Independent Windows development preview. Free client; no personal VPS required.

Live Mozilla authentication and selected/direct application egress still need validation. This preview is not a stable, security-audited production VPN. Service eligibility, region restrictions and quotas apply.

Your first connection

  1. Open Account and add your own Mozilla account. Enter any verification code yourself. The app does not store your password.
  2. Use Apps to tick the applications that should use VPN, then save. Other apps use the direct outbound.
  3. Choose a server in Locations. Lower measured latency is listed first; favorite the places you use regularly.
  4. Connect from Home and approve Windows routing if requested.

Additional accounts stay separate and are selected manually. Their normal service quotas do not combine or reset. Only web TCP ports are supported; selected-app UDP is blocked.

Helpful shortcuts

Ctrl+D: disconnect · Ctrl+L: locations · Ctrl+K: apps. The tray menu provides favorites, recent locations and quit. Change language, theme and recovery in Settings.
