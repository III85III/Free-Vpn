III85III VPN 2.1.0-preview.1 — independent Windows development preview

The local controller, Mozilla protocol client, HTTP/2 gateway, native test
interface, vault helper and route host are implemented for III85III.
This is an unofficial Mozilla service client. Mozilla names and marks
belong to their owners; no endorsement is implied.

Neutral dependencies are bundled without reassigning their authorship:

- Node.js runtime: licenses/Node-LICENSE.txt.
- SagerNet sing-box routing binary: GPL-3.0 and upstream notices under
  licenses/. The matching release source archive is included there.
- Lato: SIL Open Font License 1.1 in assets/fonts/OFL.txt.
- Vazirmatn: SIL Open Font License 1.1 in assets/fonts/Vazirmatn-OFL.txt.
- Windows and Microsoft .NET Framework: existing system dependencies.

This build contains no binary, source archive or icon from the prior
third-party Firefox VPN Client. It does require Mozilla's remote service
and normal account entitlements. It has no personal III85III VPS/backend.

This is a test candidate. Real owner authentication, remote tunneling and
separate selected/direct app egress remain to be validated.
