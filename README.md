# III85III VPN

**A free Windows client for your own eligible Mozilla account.**

[**⬇ Download Windows Setup (.exe)**](https://github.com/III85III/III85III-VPN/releases/download/v2.1.0-preview.3/III85III-VPN-Setup.exe)

One installer includes the application and required components. **English by default**; Persian is available in Settings.

> **Development preview.** In-app sign-in still fails for some users with HTTP 406, even when browser sign-in succeeds. The separate code window does not resolve this service security check. Live routing, DNS and IPv6 validation is pending.

- Choose which applications use VPN; other applications use the direct outbound.
- Favorites, latency sorting, tray controls, manual account profiles and light/dark themes.
- No personal VPS. Mozilla determines service eligibility, regions and quota.
- Web TCP ports 80/443/8080/8443 only; selected-app UDP is rejected. Live egress, DNS and IPv6 validation is pending.

Use **your own Mozilla account and Mozilla password**. No developer account or session is included.
